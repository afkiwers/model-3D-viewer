STEP Viewer

View latest release

Drag to rotate, right-drag to pan, scroll to zoom, double-click to set the rotation centre. Click a numbered marker to read about that part.

The HTML for the viewer above

<div class="step-viewer"
     data-src="models/Connector.stp"
     data-markers="models/Connector.markers.json"
     data-height="560"></div>

<script src="step-viewer.js"></script>

Marker editor

With data-editor="true" the toolbar gets an "Add marker" button. Click the model to place a marker, type its title and text straight into the card, then copy the JSON into your markers file.
